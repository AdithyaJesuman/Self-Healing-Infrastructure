# User Guide: AIOps Autonomous Platform

Welcome to the comprehensive user guide for the AIOps Autonomous Self-Healing Platform. This guide covers the operational procedures for both the Web Command Center UI and the Terminal CLI.

## Web Command Center UI (`http://localhost:8001`)

The Web UI is structured into 10 Enterprise Studios, each designed for specific SRE, Platform Engineering, and MLOps workflows.

### 1. Live Telemetry & Anomaly Stream (`/`)
This is the main dashboard. It subscribes to a single-source Server-Sent Events (SSE) stream delivering real-time metrics at high throughput.
- **Features**: Visualizes real host `psutil` metrics using zero-jitter Recharts SVG area charts.
- **Chaos Observation**: When an anomaly is injected, observe the dynamic chaos exponential decay curve driven by the `ACTIVE_CHAOS_OVERRIDE` flag.
- **Throughput Meter**: Tracks real-time engine throughput, capable of reaching 1,375,792 ops/sec.

### 2. Log Intelligence Studio (`/logs`)
Monitor system logs in real-time.
- **Parsing**: Automatically parses logs by severity (INFO, WARN, ERROR, CRITICAL).
- **Tagging**: Integrates with the Anomaly Detection Engine to provide vector anomaly tagging on anomalous log entries.

### 3. Digital Twin Simulation Studio (`/twin`)
Before deploying fixes in production, test them safely in the Digital Twin.
- **Parameters**: Adjust sliders for DB pool size, replica counts, and traffic scaling.
- **Mathematical Validation**: Visualizes queueing theory metrics (Arrival Rate $\lambda$, Service Rate $\mu$, Waiting Time $W_q$) under different configurations.

### 4. Causal Graph & RCA Studio (`/graph`)
Investigate the root cause of systemic failures.
- **DAG Traversal**: Visualizes the microservice Directed Acyclic Graph.
- **Root Cause Analysis**: Computes lag-1 root cause scores to pinpoint the exact failing node.
- **Remediation**: Recommends automated remediation action cards with blast radius estimation.

### 5. CSV Ingestion & NAB Benchmark Studio (`/csv-analyzer`)
Ingest historical datasets for offline analysis and benchmarking.
- **NAB Datasets**: Comes pre-loaded with 49 real production Numenta Anomaly Benchmark (NAB) datasets (AWS EC2, RDS, ELB).
- **Custom Ingestion**: Upload custom CSVs. Anomalies detected are mandatorily logged directly to the Incident Memory.

### 6. Topology & Microservice Mesh (`/overview`)
A high-level view of the 7-node microservice grid (`payment-api`, `auth-service`, `db-primary`, `order-processor`, `notification-svc`, `inventory-db`, `ingress-gateway`).
- Displays real host CPU/RAM sync alongside simulated latency and error rates.

### 7. Incident Memory (`/incidents`)
Your automated SRE memory store.
- **Vector Search**: Backed by ChromaDB for semantic search of past incidents.
- **Post-Mortems**: Access interactive SRE Post-Mortem modals generated by Layer 9 of the pipeline.
- **Export**: JSON audit log exporter.

### 8. Chaos Engineering Lab (`/chaos`)
Inject faults to test system resilience.
- **Vectors**: 8 injection vectors including CPU Spike, Memory Leak, DB Pool Exhaustion, Network Latency, Disk I/O Saturation, Thread Exhaustion, Packet Loss, and Cascading Failovers.
- **Auto-remediation**: Watch the multi-agent brain automatically detect and deploy fixes, visualizable via auto-remediation curves on the Live Telemetry stream.

### 9. QA Benchmark Runner (`/tests`)
Execute rigorous platform integrity checks.
- Runs 15 platform integrity checks and model accuracy benchmarks to ensure the 98.2% precision and 0.73 µs decision latency standards are met.

### 10. Architecture Docs (`/docs`)
In-app technical documentation viewer for quick reference to the system's architecture and design patterns.

## Standalone Terminal CLI

For environments without graphical capabilities or for automation scripts, the platform offers a standalone CLI via `aiops_cli.py`.

### Execution
```bash
python aiops_cli.py
```

### Features
- **Rich TUI**: Built with the `rich` library for a beautiful terminal interface.
- **Full Pipeline Execution**: Runs the complete 10-layer pipeline autonomously in the terminal.
- **Chaos Injection**: Trigger faults directly from the CLI prompts.
- **QA Benchmark Runner**: Execute the test suite and output results directly to standard out.
